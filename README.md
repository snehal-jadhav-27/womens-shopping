# 🛍️ Women's Shopping Website

A modern and responsive women's online shopping website built using **React.js**. The project provides a simple e-commerce experience where users can browse products, search for items, add products to cart and wishlist, and complete the checkout process.

## 🌐 Live Demo

👉 **[View Women's Shopping Website](https://womens-shopping-eight.vercel.app/)**

## 📌 Features

* 🏠 Modern Home Page
* 👗 Women's fashion product categories
* 🔍 Product search
* 🛒 Add to Cart
* ❤️ Add to Wishlist
* 📦 Product Details
* 🔐 Login and Registration
* 💳 Checkout and Payment Options
* 📱 Responsive design
* 🔥 Sale section
* 💾 Local Storage for cart and wishlist data
* 🚀 Deployed on Vercel

## 🛠️ Technologies Used

* **React.js**
* **JavaScript**
* **HTML5**
* **CSS3**
* **React Router**
* **Local Storage**
* **Vercel**

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project

```bash
cd womens-shopping
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm start
```

The application will run locally at:

```text
http://localhost:3000
```
